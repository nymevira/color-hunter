# Color Hunter

A small, browser-based color matching game made with plain HTML, CSS, and JavaScript. No packages, build step, or account required.

## Play

Open `index.html` in a browser and select **Start hunting**. Find the tile that matches the named target before the 30-second timer runs out. Correct matches earn 10 points; mistakes reset your streak. Your best score is saved in the browser.

Use **Dark mode** to switch to a dark color scheme or **Color-blind palette** to switch to an alternate palette designed for clearer color distinctions. Both display settings are saved in the browser.

## Project files

- `index.html` contains the page structure and game interface.
- `styles.css` controls the layout, colors, and responsive styling.
- `script.js` handles the timer, color rounds, score, streak, and saved best score.
